# Vaulture Desktop

Vaulture is a zero-knowledge desktop vault for storing sensitive information securely.

All encryption happens locally on your device.  
Vaulture never has access to your encrypted data.

---

## Downloads

Download the latest version from the [**Releases**](https://github.com/baxanvictor/vaulture-desktop/releases) page.

Supported platform:
- macOS (DMG)
- Windows (MSI)
- Linux (DEB)

---

## Early Access / MVP

Vaulture is currently in early access.
- No auto-updates yet
- No code signing or notarization yet
- Expect rough edges and UX improvements
